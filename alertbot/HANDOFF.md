## 1. 미해결 — 왜 대시보드를 아직 안 만들었나

**장중 순매수 값이 정산 시점에 재배분된다.** 이걸 모르고 백필하면 잠정치와
확정치가 섞인다.

네이버 시간별 표에 그 순간이 그대로 찍혀 있다 (2026-09-03 코스피):
```
18:06  개인 -9,552  외국인   +414  기관계 +9,143   ← 재배분 후
18:04  개인 -9,552  외국인 -4,232  기관계 -2,153   ← 재배분 전
```

| 코스피 KRX | 장중(~18:04) | 확정(18:06~) |
|---|---|---|
| 개인 | -9,552 | -9,552 |
| 외국인 | **-4,232** | **+414** |
| 기관 | **-2,153** | **+9,147** |
| 기타법인 | **+15,936** | **-6** |

기관이 실제로는 +0.9조 순매수였는데 장중엔 -0.2조 순매도로 보였다. **부호가 반대다.**

**미해결 의문**: 같은 시각에 조회한 09-02·09-01·08-28은 여전히 기타법인 +1.6조다.
오늘만 -6으로 떨어진 이유가 설명되지 않는다. 가설 두 가지:
- (a) 당일 데이터가 저녁 정산 중 일시적으로 불안정한 상태였다
- (b) 재배분이 매일 일어나지만 과거 날짜에는 소급 반영되지 않는다

→ 프로브가 하루 더 돌면 판별된다.

**브리핑에 미치는 영향**: 14:30 알림의 순매수는 확정치가 아니다.
종가베팅 판단에 직접 영향을 주므로 우선순위가 높다.

## 4. 함정 (반복해서 걸린 것들)

- **Bash 히어독이 `\\n`을 실제 개행으로 바꾼다.** 파이썬 문자열 리터럴에
  `\n`을 넣어야 하면 히어독 대신 Write 툴을 쓰거나 `chr(92)+"n"`으로 조립할 것.
  증상: `SyntaxError: unterminated string literal`.
- `py -3.11`을 쓸 것. PATH의 `python`은 pandas가 없는 upbit_bot venv다.
- 서버 SSH: `~/.ssh/do_key_home`
- 콘솔이 cp949라 한글·이모지를 print하면 `UnicodeEncodeError`가 난다.
  진단 스크립트의 출력은 ASCII로.
- 텔레그램 `ReadTimeout`은 재시도하지 말 것 — 멱등 키가 없어 중복 발송이 된다.
  실제로는 전송돼 있는 경우가 많다(`editMessageReplyMarkup`으로 존재 확인 가능).
- `crontab` 수정은 반드시 `diff`로 미리 확인할 것. upbit_bot 운영 잡 2줄이 같이 있다.
